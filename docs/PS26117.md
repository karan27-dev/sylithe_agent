## Known gaps against the PS's "confidential industrial work" framing

Not required by the letter of the PS (which asks for a demonstrable local
prototype, not a production rollout), but worth disclosing rather than
leaving for a judge to find:

- **No auth / multi-user model.** Single-workstation, single-user by design.
  A real MRPL deployment would need this; the demo does not.
- **No encryption at rest** for `data/deliverables/` or the LanceDB index.
- **No automated test suite.** Correctness is checked by the `bench/*.py`
  scripts in this repo (run manually, results committed as JSON), not by
  `pytest`/CI.

**Fixed, not just disclosed:** `bench/run_sandbox_escape.py` originally found
that the sandbox's memory cap did not hold on macOS - `RLIMIT_AS` (tried in
`tools/sandbox.py:_preamble`) is silently refused by the OS, and a 2 GB
allocation went through against a 512 MB limit, exit 0, no block. Fixed with
an RSS-polling watchdog thread in the parent (`_watch_memory` in
`tools/sandbox.py`) that kills the child if its resident memory crosses the
limit, independent of whether `RLIMIT_AS` works. Re-run and verified:
**5/5 escapes now contained on macOS** (network, filesystem-outside-scratch,
timeout, memory). `python -m tools.sandbox` selftest still passes, so this
did not regress normal code execution.
