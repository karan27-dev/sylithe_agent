## Priority order for the remaining work

1. **Deliverable writers** (`tools/deliverables.py`) — emit .docx / .xlsx / .pptx. `python-docx`, `openpyxl` and `python-pptx` are already installed and already used by `tools/make_corpus.py`, so this is the cheapest large win and it unlocks demo #15.
2. **Agent loop** (`agents/`) — plan → call tool → observe → iterate. Needed for #9 and #15.
3. **Sandboxed code execution** — subprocess with no network (the air-gap patch already denies it), temp cwd, timeout. Unlocks #16.
4. **`analyze_pid`** — OpenCV + networkx graph over the drawing. Unlocks #7; already declared as `pre_tool` in the YAML.
5. Handwriting sample for #8.

## Benchmark on real MRPL data

Source: MRPL Annual Report 2024-25, downloaded from the company's own site
(`admin.mrpl.co.in`), 381 pages, 13 MB. 380/381 pages carry embedded text;
only the cover needs OCR. A 24-page slice (Directors' Report) ingested at
**3.3 s/page** → 86 chunks in 79 s, so the full report is a ~21 minute
one-time cost.

| Question | Result |
|---|---|
| "What happened to crude oil prices in FY 2024-25?" | "declined from about USD 90 to around USD 70 per barrel" — **verified verbatim in source** |
| "What was the refinery throughput / capacity utilisation?" | "18.04 MMT, 120% capacity utilisation, earlier best 114%, 15.5% ethanol blending" — **all four figures verified in source** |
| "What is MRPL's Net Zero target year?" | "not in the passages" — **correct refusal.** MRPL's 2038 target lies outside the ingested slice; the slice mentions only *India's* 2070 target, and the model did not conflate the two. |

Retrieval 2.4–2.8 s, generation 8–18 s, **0 external calls** throughout.
