# SOP-7201 Rev 2 - Relief Device Set Pressure Verification

**STATUS: SUPERSEDED on 01-Jan-2026. Do not use for new assessments. Retained for audit history only. Replaced by SOP-7201 Rev 3.**

## 4.1 Acceptance

As-found set pressure shall be within +/- 3% of the specified set pressure.

## 4.2 Minimum specified set pressure

- Class-A hydrocarbon service: **16.0 barg**
- Class-B hydrocarbon service: 16.0 barg
